about=Processing algorithm version of the script "Dynamic multiscale buffer generator". It automates batch multi-scale buffer creation in an adaptive way, based on the contents of an .xlsx spreadsheet with the columns "Step" and "Meters" ("1 - Buffer Circular" and "6 - Riparian Buffer"). It automatically detects the polygons (watersheds, contribution areas, areas of influence) and the target file for the riparian buffer (line or polygon), matches polygons with points, and separates extrapolated areas. An example spreadsheet can be opened from the help panel of the algorithm.

    Requirements: Python packages pandas and openpyxl (to read the spreadsheet).

    Developed at the Aquatic Environments Studies Laboratory (GEAAQUA), State University of Mato Grosso do Sul (UEMS), Dourados, Brazil, with support from CAPES, CNPq and Fundect.
